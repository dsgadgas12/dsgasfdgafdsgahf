# CloudeGift 0.6.15

- Одобренный баннер кейсов с моделями кепки Дурова и золотого персика.
- Бесплатный кейс использует присланную карточку целиком, без обрезанной зелёной надписи.
- Превью x1–x5: непрерывное движение, две белые стрелки внутри рамки, подарки обрезаются по окну ленты. Лишней подсветки центрального подарка до результата нет.
- Монотонный фон таймера лидеров, уменьшен верхний отступ профиля.
- Админ-панель: начисление/списание Stars, выдача NFT, поиск по Telegram ID, подстановка собственного ID. Добавлена защита кнопки от повторного нажатия и обновление своего баланса/инвентаря после операции.
- Авторизация Telegram работает с API на том же домене при пустом VITE_API_URL.

## Доступ к админке

В корневом `.env` укажите свой числовой Telegram ID в `ADMIN_TG_IDS`, например `ADMIN_TG_IDS=123456789`. Несколько ID разделяются запятой. Перезапустите backend и заново откройте Mini App. Внизу профиля появится «Админ-панель». ID получателя должен принадлежать пользователю, который уже открывал приложение.

Положительная сумма начисляет Stars, отрицательная списывает. «Выдать NFT» добавляет выбранную модель в инвентарь указанного пользователя. Кнопка «Подставить мой ID» выбирает ваш аккаунт. Безопасность проверяет сервер: одного изменения интерфейса недостаточно для получения прав.

## Проверка

Production-сборка Vite/TypeScript проходит. На изолированной временной базе проверены начисление, списание, выдача NFT себе, поиск по ID, журнал операций и отказ неадминистратору. Проверены движение всех пяти вариантов превью, указатели, открытие x5 в быстром режиме и бесплатный кейс только x1. Реальные платежи и передача NFT не проводились.

При обновлении сохраните существующие `.env`, `.env.local` и базу данных. Запуск прежний: `start-local.ps1`.
