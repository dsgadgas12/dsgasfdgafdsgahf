# CloudeGift MVP 0.3 — исправления по последним референсам

## Интерфейс и анимации
- Live-полоска перенесена под верхнюю панель с логотипом CloudeGift и доступна на всех основных экранах.
- Кейсы в сетке больше не используют сгенерированные изображения подарков: карточки собираются из оригинальных PNG-моделей Telegram Gifts из пользовательского архива.
- Внутри кейса показывается медленно движущийся предпросмотр всех призов; список повторяется бесконечно в случайном порядке. Он не запускает списание и не является открытием.
- При настоящем открытии создаётся длинная случайная рулетка, серверный приз вставляется в позицию остановки, справа после него остаётся продолжение ленты. Под каждым призом отображается стоимость.
- Апгрейдер получил вращающуюся стрелку, которая останавливается в зелёной/красной зоне. При неудаче появляется отдельное окно «Подарок сгорел» с эффектом исчезновения; при успехе — конфетти.
- Для Stars и GRAM используются переданные пользователем иконки PNG.
- Кнопка возврата работает в интерфейсе и подключена к системной кнопке Back Telegram.

## Краш
- Убраны подписи «общий раунд» из интерфейса.
- Список игроков показывает аватары, имена, суммы и статусы текущего раунда: зелёная галочка при выводе, красный крест при проигрыше.
- Ставка открывается отдельным модальным окном с быстрыми суммами, минимумом 25 Stars и опцией авто-вывода по выбранному множителю.
- Авто-вывод срабатывает по данным текущего серверного состояния; при сетевой задержке сервер всё равно проверяет, успел ли игрок забрать ставку.

## Пополнение
- Добавлены три вкладки: GRAM, Stars и Подарком.
- Stars используют официальный Telegram invoice.
- GRAM показывает адрес, уникальный memo и открывает Tonkeeper с подготовленным адресом и комментарием. Перед подтверждением пользователь должен выбрать токен GRAM и ввести сумму.
- Вкладка «Подарком» использует оригинальные модели Durov's Glasses, Astral Shard и Heroic Helmet, объясняет правила и ведёт в чат https://t.me/cloudegift.

## Важные ограничения
- Автоматический мониторинг Jetton GRAM и автоматическое зачисление пока не подключены: для этого нужен подтверждённый master-контракт GRAM и источник индексирования транзакций. Сейчас UI готовит перевод, а зачисление требует проверки.
- Общий Crash получает список участников с backend через polling; для масштабирования на большое количество игроков нужны PostgreSQL, Redis/pub-sub или WebSocket и нагрузочные тесты.
- Это MVP, не production-релиз. Реальные депозиты, выводы и NFT-передачи нельзя считать полностью автоматизированными.
