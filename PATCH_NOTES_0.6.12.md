# CloudeGift 0.6.12

## Рулетка
- Вернул небольшие указатели над и под центральной позицией.
- Убрал постоянную подсветку заранее выбранного выигрыша: все карточки нейтральные во время прокрутки, выигрыш выделяется только после остановки.
- Реализовал от 1 до 5 параллельных дорожек. Все дорожки стартуют одновременно и останавливаются с одинаковой длительностью и кривой анимации.
- Добавил кнопку мгновенного открытия без прокрутки и общее окно результатов для нескольких открытий.
- Сохранил только выбор x1–x5 и кнопку-молнию; кнопки батла, щита и звука не добавлялись.

## Баланс и сервер
- В локальном `DEV_MODE=true` тестовый пользователь один раз получает баланс до `100000000000` ⭐. Если ему ранее начисляли 25 000 тестовых звёзд, начисляется только недостающая разница.
- Добавлен атомарный API `POST /api/cases/{case_id}/open-batch` для x1–x5. Сервер проверяет общую стоимость, списывает её в одной транзакции, выдаёт каждый результат и обновляет инвентарь.
- В production-режиме демо-начисление отключено.

## Запуск
Запускай проект через `start-local.ps1`, чтобы локальный backend включился в `DEV_MODE`, а frontend получил демо-баланс. Демо-звёзды не имеют денежной стоимости.
