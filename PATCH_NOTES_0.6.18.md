# CloudeGift 0.6.18 — восстановлены исходные шансы апгрейдера

- В апгрейдере восстановлена исходная формула версии 0.6.16: `min(95%, стоимость исходного NFT / стоимость целевого NFT × 100%)`.
- Та же формула восстановлена в интерфейсе, чтобы отображаемый зелёный сектор соответствовал серверной вероятности.
- Сервер продолжает независимо определять исход каждого апгрейда криптографическим генератором случайных чисел. Никакие шансы не уменьшены и не добавлен принудительный сценарий побед/поражений.
- Сохранены остальные изменения версии 0.6.17: слоты без видимой надписи о 10% шансе, кейсы с гарантией дорогого NFT на каждом 20-м открытии, отдельные счётчики для пользователя и кейса, возвраты 100 ⭐ и 300 ⭐.

## Проверки

- Python compile для `backend/main.py`: passed.
- Сверка формулы backend/frontend с версией 0.6.16: passed.
- Проверены контрольные значения исходной формулы: 50% при отношении цен 0.5; 10% при 0.1; 2% при 0.02; верхний предел 95%.
- Остальные файлы 0.6.17 сохранены без изменений.

## LIVE / ДЕМО лента
- Добавлена отдельная демонстрационная строка ДЕМО под LIVE.
- Строка ДЕМО использует ту же высоту, размеры NFT-иконок, оформление наград и анимацию появления, что и LIVE.
- Демо-призы генерируются только на стороне интерфейса и не влияют на баланс, инвентарь, API или реальные выигрыши.
