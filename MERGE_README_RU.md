# CloudeGift PAWW + LIVE 0.6.22

LIVE-компонент приведён к поведению из вашего загруженного архива
`CloudeGift_0.6.18_upgrade_odds_restored.zip`: одна строка LIVE с реальными событиями,
анимацией призов и без искусственной второй ДЕМО-ленты.

Опрос `/api/live` из PAWW сохранён (каждые 5 секунд после авторизации).
Функции заявок на вывод, история пользователя и админское управление заявками сохранены.

## Сборка для Bothost

В корне проекта выполните `./build-for-bothost.sh` на Linux/macOS или
`build-for-bothost.ps1` на Windows с Node.js и npm. Для Bothost можно включить
собственный Dockerfile, если используете Docker-вариант сборки.

В Bothost сохраните прежние переменные окружения и постоянную базу `/app/data`.
Не заменяйте базу данных.
