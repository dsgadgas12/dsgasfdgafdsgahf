# Bothost: автоматическая сборка LIVE Mini App

Предыдущий SOURCE ZIP содержал изменённые исходники, но не новую собранную папку webapp.
Поэтому старый интерфейс мог остаться без изменений.

В этом архиве добавлен Dockerfile с multi-stage сборкой:
1. Node 22 устанавливает зависимости и выполняет `npm run build` из frontend.
2. Собранный `/build/webapp` копируется в `/app/webapp`.
3. Python 3.13 устанавливает requirements.txt и запускает `bot_host.py`.

## Настройки Bothost
- Главный файл: `bot_host.py`
- Python: 3.13 (при включённом собственном Dockerfile образ Python берётся из Dockerfile)
- Включить флажок «Использовать собственный Dockerfile».
- Пересобрать/перезапустить приложение.

Сохранить прежние переменные `BOT_TOKEN`, `WEBAPP_URL`, `JWT_SECRET` и остальные рабочие настройки.
Не менять базу данных и её постоянный путь/том. Не загружать `.env` с секретами в архив.

Если сборка Docker завершится ошибкой, пришлите именно вкладку «Сборка» с полным логом.
