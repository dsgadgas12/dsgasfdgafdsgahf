# CloudeGift 0.6.9

- Added the Free Case entry to the Games home screen, using the supplied Spring and Summer artwork.
- Added a server-side free-case draw: 2 Stars is the common result; each catalog NFT priced at 800 Stars or more has an independent exact probability of 0.0000000001%.
- Rare outcomes are selected and awarded by the backend; NFT prizes are added to inventory and the 2-Star prize is credited to the account balance.
- Added persistent free-case opening records.
- Added minimum Stars withdrawal amount of 1,500.
- NFT withdrawal requests now require at least two selected gifts and are processed together; rejection restores both gifts.
- GRAM withdrawal is not enabled yet: the existing project supports GRAM top-up instructions but has no user GRAM balance ledger to validate or reserve a withdrawal.
