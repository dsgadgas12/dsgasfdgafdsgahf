# CloudeGift 0.5 — изменения по материалам пользователя от 25.11.2026

## Главное меню
- Слоты используют предоставленную пользователем прозрачную PNG-иконку игрового автомата.
- Апгрейд использует предоставленную прозрачную PNG-иконку графика роста.
- Мины используют предоставленную прозрачную PNG-иконку бомбы.
- Убраны самодельные CSS-макеты игрового автомата и графика.
- Иконка кейсов очищена: простой векторный сундук и две оригинальные модели Telegram Gifts (Scared Cat и Precious Peach), без полупрозрачной карточки вокруг коробки.

## Пополнение подарками
- Три эмодзи обычных подарков заменены на три оригинальных анимированных TGS-стикера из ZIP пользователя: Bouquet, Bow и Teddy Bear.
- Для отображения TGS добавлен Lottie renderer и декомпрессия gzip в браузере.

## Валютные иконки
- Удалены сплошные тёмная и серая подложки из иконок Stars и GRAM; сохранена прозрачность.

## Каталог
- Все 119 коллекций синхронизированы с Excel `telegram_gifts_market_stars_2026-11-25.xlsx`.
- `price_stars` обновлён по колонке `Цена на маркете TG, ⭐ (от)`.
- `price_usd` обновлён по колонке `Floor, $`.
- Исходная таблица добавлена в `catalog/`; CSV обновлён из листа `Floor по коллекциям`.
- Backend при запуске синхронизирует таблицу `gifts` с `gifts.json`, поэтому обновлённые цены попадут в базу при следующем старте backend.

## Проверки
- Все 119 названий коллекций сопоставлены с Excel.
- Все 119 цен Stars совпадают с колонкой `Цена на маркете TG, ⭐ (от)`.
- Прозрачность валютных иконок и трёх PNG-иконок меню сохранена.
- ZIP TGS проверен и добавлен без перекодирования.
- Полную сборку Vite нужно подтвердить после `npm install` на машине пользователя; в среде подготовки сетевой доступ к npm недоступен.
